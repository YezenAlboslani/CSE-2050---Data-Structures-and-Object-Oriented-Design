# CSE-2050---Data-Structures-and-Object-Oriented-Design
This repository contains my homework assignments and lab projects for CSE 2050: Data Structures and Object-Oriented Design at the University of Connecticut.
The course focuses on:
  Implementation and analysis of fundamental data structures (lists, stacks, queues, trees, graphs, hash tables).
  Object-oriented programming principles and design patterns.
  Algorithmic problem-solving with attention to efficiency and scalability.
  Writing clean, modular, and well-documented code.
Each folder corresponds to a specific homework or lab, including source code, documentation, and any supporting files. The goal of this repository is to track my progress, practice version control, and demonstrate my growth in computer science fundamentals.
